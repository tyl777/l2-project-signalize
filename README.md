# l2-project-signalize

### 📌 О репозитории

В данном репозитории на практических примерах смоделированы сценарии работы инженера L2 (Tier 2 Support / Incident Analyst): локализация аномалий в данных, анализ интеграций и проведение Root Cause Analysis (RCA).

Главная цель — продемонстрировать регламент проведения триажа для снижения MTTR и передачи на L3 только валидированных инцидентов.

---

* **/SQL_Diagnostics** — SQL-запросы для поиска аномалий в БД (зависшие заказы, расхождения статусов).
* **/API_Triage** — Сценарии проверки REST API в Postman (валидация JSON, статусы HTTP 4xx/5xx).
* **/Bug_Reports_Templates** — Примеры готовых баг-репортов для L3-разработки с шагами воспроизведения и локализацией причин
